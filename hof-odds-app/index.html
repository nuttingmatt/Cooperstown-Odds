Algorithm

How the score works

The model compares each player to Hall inductees at the same primary position, uses bWAR and fWAR as separate value inputs, estimates future career value from recent career pace and age, weights recent inductions more heavily, adjusts modern starting-pitcher expectations, and sharply caps long-retired low-WAR players with no or negligible BBWAA ballot support.

Sources

Data notes

Hall data is generated from SABR's Lahman Baseball Database, including BBWAA and Era/Veterans-style ballot rows for inducted and non-inducted players where available. MLB live search keeps active-player totals current; player cards and tables display bWAR and fWAR as separate fields.
